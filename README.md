## 🛠️ Complete Tool Directory

All utilities run 100% locally on the client using modern JavaScript and Web APIs:

### 🔤 Core Text Case Converters
* **[Title Case Converter](https://caseconvert.online/title-case-converter)** — Formats headlines according to strict APA 7th, Chicago Manual of Style, and AP guidelines with preposition/article filtering.
* **[UPPERCASE Converter](https://caseconvert.online/uppercase-converter)** — Transforms all characters into standard capital letters with Excel `=UPPER()` and developer formula cheat sheets.
* **[lowercase Converter](https://caseconvert.online/lowercase-converter)** — Converts mixed-case text to clean lowercase for URLs, tags, and database queries.
* **[Sentence Case Converter](https://caseconvert.online/sentence-case-converter)** — Capitalizes only the first word of each sentence, recognizing standard punctuation (. ? !).
* **[Capitalized Case Converter](https://caseconvert.online/capitalized-case-converter)** — Capitalizes the initial letter of every single word.
* **[camelCase Converter](https://caseconvert.online/camelcase-converter)** — Converts prose or space-separated text into JavaScript/Java standard camelCase.
* **[kebab-case Converter](https://caseconvert.online/kebab-case-converter)** — Formats strings into URL-safe, hyphen-separated kebab-case.
* **[PascalCase Converter](https://caseconvert.online/pascal-case-converter)** — Formats text into PascalCase for React components, C#, and TypeScript classes.
* **[Alternating Case Converter](https://caseconvert.online/alternating-case-converter)** — Converts text to sarcastic/meme alternating case (`aLtErNaTiNg cAsE`).
* **[Reverse Text Generator](https://caseconvert.online/reverse-text-generator)** — Flips characters or word order backward.

### 💻 Developer Casing Bridges
* **[camelCase to snake_case](https://caseconvert.online/camelcase-to-snake-case)** — Converts frontend JSON/TypeScript keys to backend Python/SQL snake_case.
* **[snake_case to camelCase](https://caseconvert.online/snake-case-to-camelcase)** — Converts database column names to camelCase JavaScript variables.
* **[PascalCase to camelCase](https://caseconvert.online/pascalcase-to-camelcase)** — Converts class identifiers to instance variable names.
* **[kebab-case to camelCase](https://caseconvert.online/kebab-case-to-camelcase)** — Converts CSS/URL identifiers into frontend code variables.

### 🧹 Text Formatting & Cleanup
* **[SEO Slug Generator](https://caseconvert.online/slug-generator)** — Creates clean, URL-friendly slugs with custom separators and stop-word removal.
* **[Text Cleaner](https://caseconvert.online/text-cleaner)** — Removes double spaces, fixes broken PDF line breaks, trims whitespace, and normalizes smart quotes.
* **[Word & Character Counter](https://caseconvert.online/word-counter)** — Real-time metrics for word count, character count (with/without spaces), reading time, and speaking time.
* **[Word Frequency Counter](https://caseconvert.online/word-frequency-counter)** — Analyzes keyword density and word distribution for SEO copywriters.
* **[Text Diff Checker](https://caseconvert.online/text-diff-checker)** — Side-by-side visual difference tool highlighting additions, deletions, and edits.

### 🔐 Encoding & Developer Utilities
* **[JSON Formatter & Validator](https://caseconvert.online/json-formatter)** — Beautifies, minifies, and syntax-checks JSON payloads with 2-space or 4-space indentation.
* **[Base64 Encoder / Decoder](https://caseconvert.online/base64)** — Encodes strings into RFC 4648 Base64 and decodes Base64 payloads securely.
* **[URL Encoder / Decoder](https://caseconvert.online/url-encoder)** — Encodes URI query parameters and decodes percent-encoded URLs.
* **[Hash Generator](https://caseconvert.online/hash-generator)** — Computes cryptographic hashes (MD5, SHA-1, SHA-256, SHA-512) directly in your browser.
* **[Epoch / Unix Timestamp Converter](https://caseconvert.online/epoch-converter)** — Translates Unix timestamps to human-readable ISO/UTC dates and vice versa.
* **[Binary Translator](https://caseconvert.online/binary-translator)** — Translates binary code (`01000001`) to readable ASCII text.
* **[Morse Code Translator](https://caseconvert.online/morse-translator)** — Encodes text to international Morse code and decodes Morse signals.

## 🔒 100% Client-Side Privacy

Unlike legacy text tools that send your clipboard contents or confidential code snippets to backend servers for processing:

1. **Zero Server Logging**: All text manipulation is performed in-memory using client-side JavaScript.
2. **Zero Storage**: No inputs, outputs, or files are ever stored in a database or server filesystem.
3. **Offline Ready**: The application continues to transform text even when disconnected from the internet.

## 💻 Local Development Setup

To run the application locally or contribute to new conversion utilities:

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18.0 or later)
* [npm](https://www.npmjs.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/SabtainAliWazir/case-reimagined.git

# 2. Navigate to the project directory
cd case-reimagined

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) in your browser to view the application.

### Production Build

```bash
# Build optimized static production bundle
npm run build

# Preview production build locally
npm run preview
```
